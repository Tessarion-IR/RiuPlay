> [!WARNING]
> **Alpha pre-release.** RiuPlay 0.1.0-alpha.1 is the first public build. It is meant for testing and feedback, and it is **not stable or production-ready**. The Windows builds are **not code-signed**.

RiuPlay is a local-first, open-source media app for Windows. It brings video, anime, manga, audio and ASMR into one library, from your own files, your own servers and source extensions you choose. There is no account and no cloud backend.

## Highlights

- **One library for video, manga and audio:** library statuses, favourites, collections, progress, and Continue Watching, Reading and Listening.
- **Your own media:**
  - add links, local files or folders (files are never copied);
  - built-in video player (HLS, DASH, MP4);
  - continuous manga reader;
  - audio player with media keys.
- **Your own servers:** connect a Suwayomi (manga) or Kikoeru (audio and ASMR) server, browse it, and add titles to your library. Passwords are encrypted with Windows DPAPI.
- **Extensions and sources:**
  - install scripted source extensions from HTTPS repositories;
  - repositories start "not reviewed", and permissions are shown before install;
  - a **Discover** catalog lists known starting points, with license and maintenance facts. Nothing is added automatically.
- **Unified search** across sources and your own library, plus video, manga and audio activity on Profile and History.
- English, Russian and Ukrainian interface. Some new screens are English only.

## Install

| File | What it is |
|---|---|
| `RiuPlay-v0.1.0-alpha.1-setup.exe` | Installer for your user account (no administrator rights needed) |
| `RiuPlay-v0.1.0-alpha.1-portable.exe` | Portable build that runs without installing |
| `SHA256SUMS.txt` | SHA-256 checksums of both files |

1. Download the installer or the portable build. Windows 10/11 x64 is required.
2. Check the file's checksum against `SHA256SUMS.txt`:
   ```powershell
   Get-FileHash .\RiuPlay-v0.1.0-alpha.1-setup.exe -Algorithm SHA256
   ```
3. Run the file. The builds are unsigned, so SmartScreen may warn you. Choose **More info → Run anyway** only if the checksum matches.

Your data is kept in `%APPDATA%\RiuPlay\`, and uninstalling doesn't remove it. The in-app updater only offers stable releases, so install later alphas from the Releases page.

## Security

- The UI runs with context isolation and sandboxing, and has no Node access.
- Each scripted extension runs in its own Chromium-sandboxed window. It has no file, Node or Electron access, and a Windows Job Object limits its memory.
- App, extension, download and server traffic goes through one controlled network client:
  - local and private addresses are blocked unless you approve a specific server;
  - every resolved address and every redirect is checked;
  - a configured proxy is never bypassed.
- Server and proxy passwords are encrypted and stay in the main process.
- No telemetry. LAN sync is off by default.

These protections are covered by automated tests. **They have not been independently audited.** Report security issues privately through [GitHub security advisories](https://github.com/Tessarion-IR/RiuPlay/security/advisories/new).

## Known limitations

1. **Stream security:** stream URLs are checked when playback starts. Later segments, redirects and DNS changes during playback are **not yet continuously re-checked**. Desktop stream-proxy hardening is deferred.
2. **Suwayomi and Kikoeru:** both are tested against disposable fake servers only. They have **not yet been verified against real servers**. Added titles don't pick up new chapters or tracks, and Kikoeru lyrics and subtitles are not imported.
3. **UI verification:** the Media servers screens, the Discover catalog and the permission dialog have **not yet had a full manual interactive test**.
4. **APK (Java) sources:** these run outside the extension sandbox. They stay **off by default** and need an explicit opt-in. **This build doesn't include the Java host**, so APK sources are unavailable.
5. **Discord Rich Presence** needs `RIUPLAY_DISCORD_CLIENT_ID` at build time. This build has none, so it **stays off**.
6. **AniList sign-in** needs an AniList client id at build time. This build has none, so it is unavailable.
7. **Unsigned, Windows-only builds.** Other platforms are not part of this release.

## Reporting bugs

Open an issue with the [issue templates](https://github.com/Tessarion-IR/RiuPlay/issues/new/choose). Include:
- the RiuPlay version;
- your Windows version;
- steps to reproduce;
- relevant lines from `%APPDATA%\RiuPlay\logs\riuplay.log`.

**Remove personal data, server addresses, passwords and tokens** from log lines first.
