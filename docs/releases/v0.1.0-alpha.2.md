> [!WARNING]
> **Alpha pre-release.** RiuPlay 0.1.0-alpha.2 is for testing and feedback. It is **not stable or production-ready**, and the Windows builds are **not code-signed**. 0.1.0-alpha.1 stays available.

RiuPlay is a local-first, open-source media app for Windows: video, anime, manga, audio and ASMR in one library. This release makes it **extension-powered**: install a source with one click and its titles appear in the right section, with search, title pages, the native player or reader, and saved progress.

## What's new

### Sources fill the Video, Manga and Audio sections
- **Built-in RiuPlay repository**, no address to type: Internet Archive open films and animation, Pepper&Carrot (manga), LibriVox audiobooks and open audio. Files are checked against SHA-256 hashes before install.
- Installed sources show up in their section with search, a RiuPlay title page, the native player or reader, Continue Watching/Reading/Listening, favourites and collections.

### The three ecosystems
- **Audio / ASMR: KikoFlu's source (asmr.one)**, built in. Search, works with their tracks, native audio player, Continue Listening. **Adult (R18) works are hidden by default**; a per-source setting shows them.
- **Anime: Hibiki's anime sources**, one click from Discover (clearly marked third-party and unreviewed). Titles appear in Video and open on the anime title page with Hibiki's player and resolvers.
- **Manga: Keiyoushi**, inside RiuPlay, with **no Suwayomi server and no Java to install**. One click adds Keiyoushi's repository; its extensions are listed under Sources → Extensions and install with one click. Titles, chapters and pages appear in the Manga section and the native reader.

### Security: APK extensions run confined
- RiuPlay ships its own Java 21 runtime and starts it inside a **Windows AppContainer with no capabilities** and a **Job Object**. The Java host can read only its runtime and write only its data folder, cannot start programs, and has **no network of its own**.
- Every connection it needs is opened by RiuPlay under its usual rules: public websites on ports 80/443 only, every resolved address checked and pinned, your proxy never bypassed.
- A Keiyoushi extension installs only if its signed jar is signed by the key Keiyoushi publishes, checked in a separate confined process and again by the host. Keiyoushi's index must be signed for that same key.
- The old "full Windows user rights" opt-in is gone. The Java host can still be switched off in Settings.

## Install

| File | What it is |
|---|---|
| `RiuPlay-v0.1.0-alpha.2-setup.exe` | Installer for your user account (no administrator rights needed) |
| `RiuPlay-v0.1.0-alpha.2-portable.exe` | Portable build that runs without installing |
| `SHA256SUMS.txt` | SHA-256 checksums of both files |

Windows 10/11 x64. Check the download with `Get-FileHash <file> -Algorithm SHA256` against `SHA256SUMS.txt`. SmartScreen may warn because the builds are unsigned: choose **More info → Run anyway** only if the checksum matches. Your data stays in `%APPDATA%\RiuPlay\`; alpha.1 profiles open in alpha.2.

- The anime gate uses a source in Hibiki's format serving the Blender Foundation's open movies (Sintel, Elephants Dream, Big Buck Bunny; Creative Commons BY 3.0) from archive.org: Sintel played at 2048×872 and resumed at 5:14 after a restart.

## Known limitations

- **Hibiki's own sources were not played in testing.** They read unofficial streaming sites, so the anime pipeline (playback, controls, saved progress, resume) was verified with a Hibiki-format source serving Creative Commons films. Hibiki's sources were verified up to their catalogues; individual sites change and break often.
- **Some sites are blocked on some networks.** RiuPlay refuses sites that resolve to private addresses (a common DNS block) rather than connecting. On the test network this affected MangaDex, Webtoons and others.
- **APK extensions** (Keiyoushi, Aniyomi): Windows only; they may contact any public website (they declare no hosts); extensions that draw their own text pages or need a JavaScript engine (QuickJS) don't work; WebView-based ones (e.g. Manga UP!) were not tested end to end; their settings screens and icons are not shown yet. The Java host adds about 52 MB.
- **Third-party content.** Hibiki's sources and most Keiyoushi extensions read unofficial sites, and asmr.one serves commercial works it holds no license for. RiuPlay is only a client; lawful use is your responsibility.
- asmr.one lyrics are matched but not yet shown in the player.
- Unchanged from alpha.1: stream URLs are checked when playback starts but HLS/DASH segments are not re-checked continuously; Suwayomi/Kikoeru were tested against fake servers only; Discord presence and AniList sign-in are off in release builds; newer screens are English only; builds are unsigned and Windows-only.
